# Redesign in vertical slices

The UI redesign will be delivered as vertical slices tied to user-facing risks rather than as one broad visual rewrite. This keeps each change shippable and testable while preserving the product decisions captured in `CONTEXT.md`: a local-first Markdown note app, a default writing surface, scoped search, lightweight tags, stable note actions, and tuned themes.

The initial slice order is: first-run and theme foundations, sidebar note list and actions, editor view modes and note metadata, then confirmation and modal polish.
